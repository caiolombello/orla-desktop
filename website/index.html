04O CAMINHO PELA FRENTE

Uma ideia que
vai mais longe.

A versão alpha avança pelo dock, agora com perfis manuais. Integrações mais completas e novas superfícies continuam no roadmap.

A

Mais desktop, num só lugar

Barra superior opcional, menus globais compatíveis e uma Central de Controle configurável.

PLANEJADO
B

Um launcher para suas ideias

O código inclui um launcher experimental com build separado. Integração completa, foco global no Wayland e extensões continuam planejados; ele não vem no pacote do dock.

PLANEJADO
C

Seu setup, mais conectado

Spotify e Steam mais completos, troca de áreas de trabalho e associação automática de perfis a Activities/desktops. Os perfis atuais são manuais.

PLANEJADO
D

Notificações que encontram você

Toast, HUD e Dynamic Island, integrados com as notificações nativas do Plasma.

05PRIMEIROS PASSOS

Um dock novo
na sua orla.

Orla Dock 0.2.5 alpha é para quem quer experimentar e ajudar o projeto a crescer.

REQUISITOS
KDE Plasma 6.7+·Python 3.10+·Qt 6 / PySide6
git clone https://github.com/caiolombello/orla-desktop.git

Depois, entre na pasta do projeto e siga os passos de instalação do README. O pacote pode ser gerado localmente pelo script de build.

O ZIP da 0.2.5 também inclui uma CLI experimental para consultar updates com uma versão informada. A atualização continua manual.
