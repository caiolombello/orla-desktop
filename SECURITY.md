# Security policy

Orla Desktop is an alpha project. Please do not report suspected vulnerabilities in public issues.

Use GitHub's **Report a vulnerability** action in the repository's Security tab to send a private advisory to the maintainers. Include the affected version, a concise impact description, and steps to reproduce. Do not include real tokens, account data, calendar contents, or private state files in the report.

There is no separate supported-version matrix yet. The maintainers will confirm receipt and coordinate a fix and disclosure when possible; response times are not guaranteed while the project remains in alpha.
