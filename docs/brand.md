# Orla Desktop brand

## Name

**Orla Desktop** is the project and future component family. **Orla Dock** is the first available component. “Orla” evokes a shoreline: a clear edge that keeps frequently used things close while leaving room for the desktop. The name is a product identity, not a claim of affiliation with KDE or Apple.

## Visual direction

Use a quiet, coastal palette with dark ink, mist, and a restrained sea-glass accent. Keep surfaces legible against KDE themes, make the accent support focus and selection, and preserve a high-contrast text color in both light and dark treatments. Rounded geometry can echo a shoreline, but avoid copying Apple marks, interface artwork, or product names.

- Midnight ink: `#111923`
- Slate: `#283542`
- Sea glass: `#69D7C2`
- Pale foam: `#EAF4F1`
- Warm paper: `#F4F0E8`

These are identity tokens for Orla's own landing page and artwork. The dock's existing Glass, Midnight, and Paper theme colors remain user-facing app settings and may evolve independently.

## Voice and product naming

- Say **Orla Desktop** for the project, **Orla Dock** for the current applet.
- Describe available behavior in the present tense only when it exists in the released code.
- Mark proposed components and layouts as planned or conceptual.
- Use plain language, short labels, and Portuguese Brazilian and English project information.

## Compatibility

The visible product name may change without changing the existing Plasma package ID `org.caiodock.dock` or D-Bus service `org.caiodock.Integrations`. Keep those identifiers stable unless an explicit migration is added.
